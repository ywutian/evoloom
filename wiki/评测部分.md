# EvoLoom 评测与证据状态

EvoLoom 当前公开的评测能力是一套可复现的 smoke integration suite，
用于验证 Agent Harness 的关键执行链路，而不是行业 Benchmark 成绩。

## 当前可以复现的内容

仓库包含 6 个小型隔离任务，覆盖文件创建、精确编辑、错误修复和结构化
输出等基本能力。每次运行都会保留：

- 任务配置与实际命令；
- stdout、stderr 和最终工作区；
- 每个确定性检查的结果；
- wall time、可获得的 token 统计和成本字段；
- Pass@1 与 Wilson 95% 置信区间。

运行方式和结果目录说明见 [`BENCHMARK.md`](../BENCHMARK.md)。

## 不能从当前仓库得出的结论

当前仓库没有提交 GAIA、HLE 或其他大型 Benchmark 的逐题结果、冻结题集、
完整 runner 配置和原始运行日志。因此，不能根据公开仓库声称：

- EvoLoom 在 GAIA 或 HLE 上达到某个 Pass@1；
- EvoLoom 优于 HiRA、OpenHands 或其他 Agent；
- Memory folding 或 Skills evolution 带来某个确定百分点的提升；
- 6 个 smoke tasks 构成具有统计意义的成功率。

早期内部实验数字不作为公开证据，也不用于 README、Release 或项目介绍。

## 发布统计结果前需要补齐的证据

正式结果至少应满足：

1. 冻结并公开不少于 30 个代表性任务及 fixture 版本；
2. 记录模型、provider、日期、工具策略、网络权限和预算；
3. 保留所有任务行，包括失败、超时和异常；
4. 发布逐题结果、聚合脚本、Pass@1 置信区间和耗时分布；
5. 对照实验使用相同模型、任务、预算、工具和 judge；
6. 消融实验提供配对结果，而不是只给聚合百分比。

在这些条件满足前，EvoLoom 的量化证据仅用于工程回归，不作为模型或
Agent 能力排名。

# EvoLoom UI fonts

The frontend self-hosts Latin WOFF2 subsets for the following fonts. Each is
distributed under the SIL Open Font License 1.1.

- Familjen Grotesk: https://github.com/Familjen-Sthlm-Grotesk/Familjen-Grotesk
- Atkinson Hyperlegible: https://github.com/googlefonts/atkinson-hyperlegible
- IBM Plex Mono: https://github.com/IBM/plex

The full license text and required copyright notices are included in
`../LICENSES/OFL-1.1.txt` and `../THIRD_PARTY_NOTICES.md`.

Chinese text intentionally falls back to the platform's native Chinese UI font
to avoid shipping a multi-megabyte CJK webfont in the public demo.

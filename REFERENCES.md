# Research references

EvoLoom is informed by public work on agent memory, tool use, and skill
evolution. To keep redistribution rights clear, this repository links to
official publication pages instead of storing third-party paper PDFs.

- AutoSkill: Experience-Driven Lifelong Learning via Skill Self-Evolution
  - arXiv: https://arxiv.org/abs/2603.01145
  - Code: https://github.com/ECNU-ICALK/AutoSkill
- DeepAgent: A General Reasoning Agent with Scalable Toolsets
  - arXiv: https://arxiv.org/abs/2510.21618
  - DOI: https://doi.org/10.1145/3774904.3792460

These references are acknowledgements, not claims of implementation parity or
benchmark comparability.
